# 《黑白校园》作品介绍

## 一、作品概述

《黑白校园》是一款使用 Unity 制作的黑白手绘风格 2D 银河城动作原型。玩家从校园的复生区出发，穿过六个由门连接的房间，在移动、跳跃、收集和战斗中逐步抵达明亮天台，并面对钟表 Boss。

作品用单色场景和少量红蓝强调色建立视觉识别：黑白负责表现校园的压抑与梦境感，红色突出攻击与危险，蓝色辅助表达可交互或系统信息。

## 二、玩法流程

1. 玩家使用 `A / D` 左右移动，使用 `K` 跳跃。
2. 玩家使用 `J` 进行近战攻击，攻击命中敌人后造成 1 点伤害。
3. 纸片幽灵负责巡逻、追踪和远程攻击，钟表敌人负责近战；最后一关的钟表作为放大的 Boss，拥有近战和远程攻击。
4. 每个房间配置一个 Coin。玩家拾取当前房间的 Coin 后，才能使用 `E` 与门交互并进入下一房间。
5. 玩家和敌人的生命值均为 7。受击时显示扣血数字、闪烁和击退反馈，生命值归零后对象消失。

## 三、关卡结构

| 房间 | 主要内容 |
| --- | --- |
| 01 复生区 | 高空坠落入场与复活区 |
| 02 教学室 | 移动和跳跃教学 |
| 03 Boss 教室 | 钟表敌人和战斗压力 |
| 04 夜间走廊 | 巡逻、收集和门锁节奏 |
| 05 亮起的教室 | 逐渐变亮的过渡空间 |
| 06 明亮天台 | 钟表 Boss 和最终挑战 |

## 四、技术实现

- Unity 2022.3.62f1c1，URP 2D。
- `Player2DController.cs` 负责玩家移动、跳跃和地面检测。
- `EnemyAI.cs`、`EnemyPatrol.cs` 负责敌人的巡逻、追踪和朝向。
- `EnemyAttack.cs`、`EnemyRangedAttack.cs`、`EnemyProjectile.cs` 将 Animator 动作与伤害时序连接起来。
- `Health.cs` 统一处理生命值、受击数字、闪烁、击退和死亡。
- `RoomContentSpawner.cs` 在 `main` 场景中创建房间钥匙、敌人和第六房间 Boss，并把运行时内容集中到层级 `Main Content` 下。
- `CoinRoomPickup.cs` 和 `SchoolDoor.cs` 实现“拾取当前房间 Coin 后才能开门”的推进机制。
